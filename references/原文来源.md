## 取用方式

联网时直接读原页面：

```bash
curl -fsSL --compressed "https://letters.thedankoe.com/p/how-to-fix-your-entire-life-in-1" \
  -A "Mozilla/5.0" | python3 -c "import sys,re,html;t=sys.stdin.read();s=t.find('class=\"body markup\"');t=t[s:];t=re.sub(r'<(h[1-6]|p|li|br|/p)[^>]*>','\n',t);t=re.sub(r'<[^>]+>','',t);print(html.unescape(re.sub(r'\n{3,}','\n\n',t)))"
```
